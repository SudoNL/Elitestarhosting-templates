# Contributing to ElitestarHosting Templates

Thank you for your interest in contributing!
This project aims to provide high-quality, clean, and modern web hosting templates. To maintain consistency and ensure the best experience for all users, please follow the guidelines below.

---

## 📌 How to Contribute

### 1. Fork & Clone the Repository

* Fork this repository to your own GitHub account.
* Clone your fork locally using your preferred method or Git client.

### 2. Create a New Branch

Use clear and descriptive branch names, for example:

```
feature/new-navbar
fix/footer-alignment
update/theme-colors
```

---

## 🛠 Code & Template Guidelines

### HTML

* Use semantic HTML (`header`, `main`, `footer`, `section`, etc.).
* Avoid inline CSS unless absolutely necessary.
* All HTML must be valid according to W3C standards.

### CSS

* Keep styling clean, consistent, and well-organized.
* Use CSS variables where possible (`:root { --main-color: ... }`).
* Avoid unused, duplicated, or overly large CSS blocks.

### JavaScript

* Prefer clean, native JavaScript.
* Avoid heavy frameworks unless required.
* Ensure compatibility with all modern browsers.

---

## 🎨 Design Guidelines

* Templates should follow the visual identity of ElitestarHosting.
* Clean, modern, and minimal layouts are preferred.
* All images must be copyright-free or licensed for reuse.

---

## 📂 Directory Structure

When adding a new template, use the following structure:

```
/templates
   /template-name
      index.html
      /assets
         /css
         /js
         /img
```

---

## ✔ Pull Request Guidelines

* Provide a clear description of what you added or changed.
* Include screenshots if your changes affect UI or design.
* Fully test your template before opening a pull request.
* Link to an existing issue if applicable.

---

## 🐞 Reporting Issues

Submit issues with:

* A clear and descriptive title
* A detailed explanation of the problem
* Steps to reproduce
* Optional screenshots
